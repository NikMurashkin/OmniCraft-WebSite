Global System Settings: Interface, Artificial Intelligence, and Security ​

Unlike workspace-specific settings, where the craftsman configures economic parameters for a single business (hourly labor rates, base markups, and overhead categories), Global System Settings establish foundational operating rules for the entire software suite and the local database.

To access the configuration window, select «File» ➔ «Program Settings» in the application menu. Parameters are structured across two dedicated tabs: «General» and «AI Agent».

General Tab ​

This section contains fundamental operating parameters, financial reporting rules, UI themes, and system diagnostics.

1. Interface Language ​

The software suite provides complete bilingual localization. Upon the initial launch, the system automatically detects your operating system locale and adapts the display language.

The craftsman can switch the active language at any time between «Русский» and «English»:

  • Application Mechanics: Changing the language requires a full restart of the application. This ensures that all modal windows, input forms, cash flow categories, and validators are cleanly reloaded from dictionary files into memory.

2. Accounting Currency ​

By default, the system reads your national currency symbol from the regional settings of your operating system (e.g., ₽, $, €, ₸, ₺, Br). To select another monetary unit, an interactive search selector is provided: click on the currency field and type the name or standard 3-letter currency code (e.g., Euro, Lira, USD, KZT).

Protecting Historical Records

The currency selector is automatically locked as soon as the first transactional record enters the database: raw material purchases, equipment acquisitions, batch releases, or cash transactions.

This safeguard protects the mathematical integrity of your books. If the program permitted arbitrary currency changes retroactively, previous batch cost calculations, cash register balances, and managerial analytics would instantly lose consistency.

Relocating Your Workshop

If you relocate your business to another country and transition to a new operational currency, execute the «Reset Accounting» procedure (detailed in the maintenance section below). This creates a fresh financial slate in your new currency while preserving all machinery records, material catalogs, recipe specifications, and customer lists.

3. Appearance and Theme Presets ​

To ensure optimal visual comfort during extended workshop sessions under varying studio lighting, the application offers versatile interface customization:

  • Theme Mode:
    • «System (Auto)» — synchronizes light or dark appearance with your operating system settings;
    • «Light» — clean light theme with high contrast, optimized for bright daylight environments;
    • «Dark» — deep dark theme that minimizes eye fatigue during late-night studio work.
  • Color Presets: Alongside the theme mode, you can select an accent color scheme. Ten balanced palettes are available: «Auto», «Nordic Mint», «Deep Ocean», «Pine Forest», «Warm Amber», «Spiced Terracotta», «Wild Cherry», «Lavender Mist», «Smoky Quartz», and «Cosmic Obsidian».
  • Dual Palette Configuration: When the system mode is active, two independent dropdowns appear, allowing you to configure daytime and nighttime accent palettes in advance.

4. Software Update Channels ​

The «Update Channel» selector determines the release pipeline from which update packages are fetched:

  • «Stable» — thoroughly tested official releases. Recommended for routine commercial workshop operations.
  • «Beta (Pre-releases)» — pre-release builds featuring upcoming tools and early improvements for craftsmen who want to test new capabilities ahead of general release.
  • «Alpha (Developer Mode)» — specialized engineering channel featuring the latest core updates. Accessible to PRO+ license holders and core contributors.

5. Diagnostics and Stability ​

  • «Send anonymous statistics and error reports»: Enables automatic transmission of anonymized crash stack traces to the developers. Diagnostic packages contain only technical error dumps and OS version details; commercial figures, recipe contents, pricing, and client records are strictly excluded.
  • «Send development mode reports»: Additional toggle for technical specialists running the application from source code or within developer environments.

AI Agent Tab ​

OmniCraft ERP includes a native intelligent assistant infrastructure powered by large language models. Integration follows the direct personal key model: craftsmen connect their own API key directly to their preferred AI provider without intermediate proxy servers.

All queries are routed directly from your local computer to the selected provider's API endpoint. Your commercial metrics, bill of materials formulas, unit costs, and client rosters remain strictly confidential.

1. Supported AI Providers ​

The settings window provides direct integration with leading global AI engines:

  • OpenAI (gpt-4o, gpt-4o-mini, o1, o3-mini);
  • DeepSeek (deepseek-chat, deepseek-reasoner);
  • Google Gemini (gemini-1.5-flash, gemini-1.5-pro, gemini-2.0);
  • Anthropic (claude-3-5-sonnet, claude-3-5-haiku, claude-3-opus);
  • OpenRouter (unified access to dozens of models via a single account balance);
  • Ollama (Local) (llama3.2, qwen2.5, mistral, deepseek-r1:8b — default endpoint http://localhost:11434/v1, no API key required);
  • LM Studio (Local) (default endpoint http://localhost:1234/v1, no API key required);
  • Custom Endpoint (Custom) — local servers and corporate OpenAI-compatible gateways.

Key capabilities of the configuration screen:

  • Isolated Configuration Profiles: Each provider maintains its own credential bundle (model, base URL, and API key). Switching between providers never overwrites settings saved for other services.
  • Direct Console Link: A dedicated button beside the key input field opens the selected provider's official developer portal to generate keys in one click.
  • Live Connection Verification: Upon saving, the system validates endpoint accessibility and presents an unambiguous status indicator.

2. Hardware Cryptographic Key Protection ​

API keys are encrypted on disk using native Windows operating system cryptography (Data Protection API). Secrets are cryptographically bound to the active user account and host machine hardware profiles.

Even if application configuration files are copied, decrypting the key on another workstation is technically impossible. When migrating a database to a new computer, the system safeguards credentials by prompting for a fresh key entry without crashes or disruptions.

3. Assistant Tools in the Application Interface ​

Connecting an AI engine activates spark-assisted analysis shortcuts across primary workflows:

  • Batch Calculator: In-depth audit of product cost breakdown, pinpointing the primary cost driver and providing safe pricing optimization advice.
  • Raw Materials Warehouse: Rapid generation of professional item descriptions, material specifications, and workshop storage protocols.
  • Production Workbench: Instant creation of practical craftsman task sheets, noting quality checkpoints and material risks.

4. Sliding Assistant Panel ​

A vertical 38-pixel docking strip is positioned on the right edge of the main application window. Clicking the strip expands the personal digital assistant:

  • Screen Context Awareness: The assistant monitors the active view (Warehouse, Workbench, Calculator, Sales) and grounds answers in current inventory data. You can toggle context sharing off in the panel header or click the eye icon to inspect the exact payload sent to the model.
  • Scope Selector: Switches between "🔒 Tab" (strict isolation restricting actions to the active screen) and "🌐 All System" (unrestricted cross-module navigation across all workspaces).
  • Human-in-the-Loop Safeguard: The assistant is restricted from mutating records behind your back. Any modifying action produces a structured proposal card with explicit «Execute» and «Reject» buttons.
  • Web Search Capabilities: The assistant safely looks up current raw material market prices, machinery specifications, and foreign exchange rates without requiring manual approval for read-only queries.
  • Local Offline Shield: When utilizing a local engine (Ollama, LM Studio), a green shield badge indicates that business data never leaves your workstation.

5. Global AI Instructions and Workshop Manifesto ​

The system prompt pipeline operates on a modular hierarchy:

  • Core Accounting Invariants: Built-in craftsman mentor guidelines, accounting rules (Moving Average Cost for raw materials, FIFO write-offs for finished goods, integer scaling for currency), and the Zero-Destruction principle are hardcoded into the core engine.
  • Custom Workshop Manifesto: An open text area where craftsmen can document domain-specific trade rules (acceptable waste margins, packaging guidelines, handling notes for delicate materials).

6. Long-Term Memory on SQLite FTS5 ​

OmniCraft ERP features native long-term memory powered by an embedded full-text search engine with BM25 ranking, eliminating heavyweight third-party dependencies.

  • Learning Modes: Toggle automated knowledge retention between explicit interactive confirmation and background autopilot.
  • Token Budget Management: Configurable token ceiling (1,000 tokens by default). Background compaction deactivates outdated or low-confidence entries as the threshold approaches.
  • Reflexion on Rejection: Rejecting a proposed action opens an optional feedback prompt. Providing a reason creates an enduring operational rule for the active tab.
  • Rule Pinning: Pin icon on assistant responses allows committing valuable guidance directly to long-term memory.
  • Knowledge Inspector: Full registry in Program Settings allows reviewing, toggling, removing, or manually inserting rules.
  • Financial Isolation: Rules created in the Personal Capital workspace are strictly partitioned from commercial manufacturing contexts.

7. External AI Agents via MCP Protocol ​

OmniCraft ERP implements the Model Context Protocol (MCP), enabling direct integration with external coding environments and autonomous agent runtimes (Cursor, Claude Desktop, Antigravity) via standard input/output (stdio).

  • Pairing Token and Instant Revocation: A cryptographically secure token governs authorization. Clicking «Revoke Token» immediately terminates external agent access.
  • Ready Configuration Export: The «Copy JSON Config» button generates complete configuration snippets for agent settings files (claude_desktop_config.json or cursor/mcp.json).
  • Trusted Mode: By default, external agents are restricted to read-only operations. Enabling «Trusted Mode» permits mutating calls such as drafting web pages or updating inventory descriptions.
  • Audit Trail: All agent invocations are recorded in system logs with call parameters, outcome status, and response latency in milliseconds.

When handling graphics, declare your source directory in the «Allowed Directories» field of assistant settings. The agent supplies the absolute path to the local asset, which the core validates and safely optimizes for the target storefront.

8. PC Agent Mode and 4-Level Security Gateway ​

For safe interaction between the assistant and local operating system utilities, OmniCraft ERP enforces a four-tier protection architecture:

  • PC Agent Mode Toggle: Disabled by default. Blocks all external command execution and host filesystem access.
  • Directory Allowlist: Craftsmen specify explicit trusted folder paths (e.g., C:\Reports; D:\Drawings), restricting file operations exclusively to those folders. Access to database files (*.db, *.sqlite) and secret credentials (.env) is strictly denied.
  • Action Authorization Matrix:
    • Class 1 (ERP Queries): Reading inventory balances, calculating costs, and compiling analytical reports execute instantly without user interaction.
    • Class 2 (ERP Mutations): Material deductions, batch commits, and sales receipts require user confirmation on interactive proposal cards.
    • Class 3 (Filesystem and Hardware): Saving report files, reading external invoices, and sending barcode labels to printers require modal confirmation of target paths and devices.
    • Class 4 (OS System Commands): Terminal command invocations trigger a critical red security dialog displaying the exact command line, validating Zero-Destruction policies, and enforcing a mandatory 3-second hardware countdown before confirmation.

9. Prompt Inspector and AI Skills Registry ​

An administrative control center for prompts and system instructions is accessible via the top menu «Help» ➔ «System Registries...». The modal screen «System Registries: AI Skills & Prompts» provides full visibility and control over model guidance across all application layers.

Purpose and Prompt Hierarchy ​

For predictable workshop operation, craftsmen need full transparency into the prompt directives steering AI behavior on each operational screen. The prompt architecture is organized into 4 distinct layers (L0–L3):

  1. L0 (System Kernel): Immutable database invariants, safety constraints, zero-destruction policies, and accounting rules (MAC, FIFO, integer scaling).
  2. L1 (Workshop Persona): Global craftsman mentor profile, communication tone of voice, and workshop domain grounding.
  3. L2 (Workspaces): Tailored operational scope for each business domain (Business, Services, Trade, Personal Capital).
  4. L3 (Module Tabs): Task-specific instructions for active workflow screens (Warehouse, Workbench, Calculator, Sales, Cash Flow).

Prerequisites ​

The inspector is callable from any screen via the window title bar menu.

Step-by-Step Procedure for Inspecting Prompts and Managing Skills ​

  1. Open the Inspector Window: In the window title bar, click «Help» (question mark icon) and select «System Registries...». The dual-pane control center opens.
  2. Navigate the System Hierarchy Tree (Left Pane):
    • Program: Review the immutable kernel L0, global persona L1, and general system context;
    • Workspaces (L2): Switch between enterprise profiles (Business & Manufacturing, Services & Repair, Trade & Retail, Personal Capital);
    • Module Tabs (L3): Select the target working screen (Warehouse, Workshop, Calculator, Workbench, Showcase, Sales Log, Cash Flow, Capital, Analytics, Settings, Personal Capital, Partners).
  3. Inspect Active Prompt Instructions (Right Pane):
    • Selecting any node in the tree renders the exact prompt text for that layer inside a monospace viewer box;
    • The text is open for reading and clipboard copying, eliminating black-box behavior.
  4. Manage the Skills Library:
    • The «Level Skills Library» section displays ready-to-use task templates scoped to the selected layer;
    • A blue badge «Built-in» denotes factory skills, while a green badge «Custom» identifies user-authored templates;
    • Use the toggle switch to deactivate non-essential skills to conserve token context;
    • The pencil icon opens custom skill editing, while the trash icon removes user templates.
  5. Create a Custom Workshop Skill:
    • Click «+ New Skill» at the bottom of the skills list;
    • Fill in the dialog fields:
      • «Skill Title»: Short descriptive title displayed in the user interface;
      • «Scope»: Scope assignment (active screen or global context);
      • «Icon»: Material Icons code identifier;
      • «Description»: Brief explanation of workshop purpose;
      • «Prompt Template»: Step-by-step guidance defining model behavior and output formatting;
    • Click «Save». The new skill registers in the catalog and appears as an interactive chip on the assistant desk.
  6. Export AI System Map to Markdown:
    • In the top-right corner of the dialog, click «Export Map (.md)»;
    • The system compiles an exhaustive Markdown document detailing all L0–L3 layers, active prompts, and registered skills, automatically copying it to your clipboard;
    • The generated map can be pasted into external IDEs or used to audit model behavior.
  7. Close Dialog: Click «Close» to return to your current workshop workflow.

Emergency Database Maintenance and Reset Tools ​

The bottom of the «General» tab provides emergency database maintenance utilities. These operations are intended strictly for exceptional situations and require deliberate confirmation.

Accounting Reset (Clear Operational History) ​

Clears transactional records while keeping the entire workshop infrastructure intact. This is ideal when concluding a trial onboarding period with test receipts and transitioning to genuine commercial bookkeeping:

Data CategoryOutcomeCovered Records
Operational JournalsComplete deletionSales receipts, material supply receipts, warehouse deduction sheets, cash flow entries, production workbench queues, FIFO allocation records
Current BalancesReset to zeroMaterial stock on hand, finished goods quantities, cash drawer balances, bank balances, accumulated cost pools
Workshop Infrastructure100% PreservedMachinery and workshop assets, material catalog and specifications, item recipes, overhead categories, supplier rosters, and client profiles

The program automatically generates a shadow database backup before executing the reset. After clicking «Reset Accounting», OmniCraft ERP prompts for an application restart, leaving a clean workshop ready for initial physical inventory counting.

Factory Reset ​

A critical operation that permanently wipes all records from the local database.

  • Wipes all database tables: catalog items, machinery, clients, recipes, configuration records, and active license keys.
  • Returns the software to the initial state of a freshly installed application.

Critical Warning: Irrevocable Data Loss

Before initiating a factory reset, always export a manual database backup via «File» ➔ «Export Data» ➔ «Database Backup (.db)» and store your software license key in a secure external location. Without a backup file, reconstructing workshop records is impossible.

Automatic Application Restart ​

Modifying core system settings (switching languages, altering themes, changing update channels, or resetting accounting) requires reloading state in system memory.

Upon saving changes, the application presents a confirmation prompt offering to restart immediately or defer until the end of your session. When performing an automatic restart, OmniCraft ERP preserves screen coordinates and window geometry, restoring your exact working viewport seamlessly.
