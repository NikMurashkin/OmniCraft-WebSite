PART 2. PRIVACY POLICY ​

2.1. No Collection of User Project Data ​

Due to the architecture prioritizing local data storage, the Licensor has no access to the User's databases. The Licensor does not collect, process, or store the personal data of the User's clients, supplier lists, trade secrets, income data, or account balances.

The Licensor does not act as a data controller or data processor with respect to information entered by the User into the Software's database.

2.2. Automatically Collected Technical Information (Telemetry) ​

To ensure the operation of the licensing system and improve the Software's quality, the Licensor may collect strictly anonymized technical telemetry:

  • Hardware ID (HWID): An anonymized cryptographic hash of hardware parameters used solely for verifying license binding and anti-piracy protection. This code does not allow the identification of an individual.
  • Technical Metrics: Interface language, operating system version, Software version, and sales transaction counter (to verify trial limits).
  • Crash Reports: In the event of a critical error, the Software generates an error log (traceback) where local PC directory paths are masked to avoid transmitting system account names.

2.3. Processing of Data During Checkout ​

  • Upon purchasing and paying for a license through an authorized payment gateway, the User provides an email address and device hardware ID.
  • By providing data, the User consents to the processing of this information by the Licensor solely for the purpose of automatic generation, delivery, and technical support of the license key.
  • To ensure privacy and minimize data collection, the email address is used solely to dispatch the message with the license key immediately upon completion of the transaction and is not saved or stored in databases on the Licensor's servers. Only the anonymized license token and the device's hashed fingerprint are stored in the license database.
  • Data processing is carried out in compliance with applicable law. Data is not transferred to third parties (except for the lawful demands of authorized state authorities).

2.4. Consent Management (Opt-Out) ​

The User has the right to withdraw consent to the transmission of analytical telemetry and crash reports at any time. To do so, simply uncheck the corresponding option in the Global Settings section of the Software. Upon disabling this parameter, the Software switches to fully offline operation (with the exception of one-time requests to verify commercial license activation).

2.5. Web Resources Usage ​

When visiting omnicraft-erp.com or interacting with the Licensor's official authorization servers, the web server may automatically log standard connection data (IP address, browser type, access time) solely for network security and DDoS mitigation. The website does not use advertising or tracking third-party cookies.

2.6. Local and Session Browser Storage ​

The website uses local session browser storage strictly to maintain the technical functionality of the user cabinet and preserve authorization status during an active user session. Data is stored locally on the user's device. Stored information is not used for tracking or marketing purposes and is automatically erased by the browser when the tab or browser window is closed.
