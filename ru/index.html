Всё, что нужно мастерской.
В единой системе.

Забудьте про разорванный учет в таблицах. OmniCraft связывает склад, верстак и кассу в умный конвейер.

Умная себестоимость (MAC)

Программа сама усредняет стоимость сырья при закупках и честно распределяет цену доставки по материалам пропорционально их стоимости, а не поровну.

Смешанные финансы

Не разделяйте искусственно личный кошелёк и кассу мастерской. Система покажет, когда бизнес окупил вложения.

Умный Верстак

Планируйте очередь. Программа сама зарезервирует сырьё под заказы по методу FIFO.

Рейтинг Time ROI

Узнайте, сколько реальных денег приносит вам один час работы над конкретным изделием.

100% Автономность и безопасность

Работайте откуда угодно. Архитектура SQLite WAL и встроенные ротационные бэкапы (GFS) защитят данные от сбоев питания, а будущая облачная синхронизация сделает работу еще удобнее.

Почему OmniCraft,
а не таблицы?

Большинство ремесленников начинают учёт в таблицах или блокнотах. Это работает, пока бизнес маленький. Но когда появляются десятки материалов, заказы на месяцы вперёд и вопросы — ручные таблицы ломаются.

Вы забываете учесть стоимость доставки, не считаете износ оборудования и теряете реальную себестоимость.

История обновлений

v1.0.0-beta.4Текущая
11 июня 2026 г.

OmniCraft ERP v1.0.0-beta.3 — Automated Anonymous Crash Reporting & Diagnostics

This release introduces an automated, non-blocking, and privacy-respecting telemetry system to help identify and fix runtime exceptions on various platforms (Windows, macOS, and future mobile ports) before they affect the user experience.

What’s New:

  • Anonymous Crash Reporter: Implemented core/crash_reporter.py to automatically capture and sanitize tracebacks (personal home directory paths are replaced with a generic [USER_DIR] token, and IP logging is bypassed on the server) and deliver them non-blockingly via a background thread.
  • Global Exception Hooks: Wired sys.excepthook, threading.excepthook (critical for background threads spawned by Flet), and Flet’s internal page.on_error to catch and report synchronous, asynchronous, and rendering errors.
  • Privacy Safeguard Checkbox: Added a global “Send anonymous crash reports” toggle in the Program Settings dialog. Updated localized strings in both English and Russian locale dictionaries.
  • Secure Web Dashboard & Endpoint: Configured a secure, self-hosted web endpoint and dashboard that receives technical telemetry, writes detailed logs to daily files, and displays a responsive dark-themed diagnostic page. Web access is restricted by a secure token, and log directories are protected by .htaccess rules.
  • Apache Directory Override: Resolved folder-level 403 Forbidden issues caused by strict parent website CMS configurations by adding directory index and rewrite overrides.
v1.0.0-beta.2
11 июня 2026 г.

First Public Beta Release This release introduces the complete local-first ERP pipeline for crafters and micro-manufacturing, establishing the foundation for inventory management, production tracking, and financial analytics.

Core Architecture & Database

  • Implemented a local-first SQLite architecture with Write-Ahead Logging (WAL) and strict foreign key constraints.
  • Integrated a financial engine based on exact integer scaling (DB_SCALE = 10000) to completely eliminate floating-point calculation errors.
  • Added a background Grandfather-Father-Son (GFS) backup system (daily, weekly, monthly, yearly, and on-close rotational backups).
  • Configured Nuitka standalone compilation for secure binary delivery.

Production Pipeline & Inventory

  • Workshop: Added asset lifecycle management, including dynamic on-the-fly residual value estimation and write-off logic for consumables.
  • Raw Materials: Implemented Moving Average Cost (MAC) logic with automatic proportional allocation of shipping costs to batch items.
  • Calculator: Created a dual-level recipe builder (raw materials + packaging) with automated labor and overhead cost distribution.
  • Workbench: Developed a dynamic production queue with real-time FIFO material reservation and deficit tracking.
  • Finished Goods: Added a showcase module utilizing data-driven FIFO batch accounting to freeze and track actual production costs versus theoretical estimates.

Sales, Finance & Analytics

  • Sales: Built a POS interface with sales channel management, custom markups, and configurable shipping payer logic.
  • Cash Flow (DDS): Implemented a ledger for manual income, expenses, and tax payments.
  • Capital: Added a real-time management balance sheet (Assets minus Liabilities) tracking the net worth of the business and personal investments.
  • Analytics: Integrated a 6-month financial pulse chart, revenue breakdown pie chart, and a unique Time ROI (profit per hour) rating system for products.

PRO Ecosystem & Licensing

  • Added Multi-Workspaces: Ability to create and manage an unlimited number of isolated databases with seamless switching via the Drawer UI.
  • Implemented My Capital: A global dashboard for tracking personal accounts, non-business assets, and automatically calculating untracked living expenses using the net worth delta across all workspaces.
  • Integrated an offline asymmetric RSA-based licensing system locked to the OS Hardware ID (HWID).
  • Added a silent background update checker utilizing an external Gist manifest.
